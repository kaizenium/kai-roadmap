# Дорожная карта Kai

Этот документ отслеживает порядок разработки языка Kai и его экосистемы. Фазы упорядочены по зависимостям, а не по датам - каждая фаза требует основного результата предыдущей. Это реалистичный уровень обязательств для проекта, который в настоящее время находится на стадии спецификации.
 
## Обозначения статусов
 
| Метка | Значение |
|---|---|
| ГОТОВО | Завершено |
| В ПРОЦЕССЕ | Активно ведётся работа |
| ЗАПЛАНИРОВАНО | Запланировано, ещё не начато |
| ИДЕЯ | На рассмотрении, не утверждено окончательно |
 
---
 
## Фаза 0 — Дизайн Языка
 
**Цель:** Зафиксировать синтаксис и семантику на бумаге.
 
| Статус | Пункт |
|---|---|
| ГОТОВО | Определить философию и целевые области применения |
| В ПРОЦЕССЕ | Спецификация языка v0.1 ([about-kai](https://github.com/kaizenium/about-kai)) |
| ЗАПЛАНИРОВАНО | Расширить примеры синтаксиса (граничные случаи: обобщённые ограничения, правила перегрузки операторов, детали системы макросов) |
| ЗАПЛАНИРОВАНО | Собрать отзывы сообщества по спецификации |
 
## Фаза 1 — Лексер и Парсер
 
**Цель:** Минимальный фронтенд, способный преобразовать исходный код Kai в AST.
 
| Статус | Пункт |
|---|---|
| ЗАПЛАНИРОВАНО | Лексер: определения токенов, обработка строковых/символьных/числовых литералов |
| ЗАПЛАНИРОВАНО | Парсер: грамматика выражений/операторов, правила приоритета |
| ЗАПЛАНИРОВАНО | Определения AST |
| ЗАПЛАНИРОВАНО | Сообщения об ошибках парсера (с указанием строки/столбца) |
 
## Фаза 2 — Семантический Анализ
 
**Цель:** Работающая проверка типов и базовая валидация.
 
| Статус | Пункт |
|---|---|
| ЗАПЛАНИРОВАНО | Таблица символов и разрешение областей видимости |
| ЗАПЛАНИРОВАНО | Проверка типов (`i8`-`i64`, `u8`-`u64`, `f32`/`f64`, `bool`, `char`, `str`) |
| ЗАПЛАНИРОВАНО | Разрешение полей и методов struct/class |
| ЗАПЛАНИРОВАНО | Применение правил видимости (`public`/`private`/`protected`) |
| ЗАПЛАНИРОВАНО | Разрешение обобщённых типов (`Vector<T>`) |
 
## Фаза 3 — Генерация Кода
 
**Цель:** Преобразовать проверенный AST в рабочий x86-64 Assembly.
 
| Статус | Пункт |
|---|---|
| ЗАПЛАНИРОВАНО | Кодогенерация для базовых выражений и управляющих конструкций (`if`/`for`/`while`/`switch`) |
| ЗАПЛАНИРОВАНО | Соглашение о вызове функций, управление стековым фреймом |
| ЗАПЛАНИРОВАНО | Расположение struct/class в памяти |
| ЗАПЛАНИРОВАНО | Интеграция блоков встроенного ассемблера (`asm {}`) |
| ЗАПЛАНИРОВАНО | Объединение вывода NASM/GAS через линковщик |
| ЗАПЛАНИРОВАНО | Веха: запуск "Hello World" (Linux x86-64) |
 
## Фаза 4 — Зрелость Компилятора
 
**Цель:** Сделать возможным написание реальных программ.
 
| Статус | Пункт |
|---|---|
| ЗАПЛАНИРОВАНО | Кодогенерация указателей/ссылок при ручном управлении памятью |
| ЗАПЛАНИРОВАНО | Порядок вызова конструктора/деструктора, наследование и виртуальная диспетчеризация |
| ЗАПЛАНИРОВАНО | Вычисление constexpr |
| ЗАПЛАНИРОВАНО | Реализация системы макросов |
| ЗАПЛАНИРОВАНО | Улучшение сообщений об ошибках и предупреждений компилятора |
| ИДЕЯ | Базовые проходы оптимизации (устранение мёртвого кода, свёртка констант) |
 
## Фаза 5 — Экосистема Инструментов
 
**Цель:** Сделать язык пригодным для повседневного использования.
 
| Статус | Пункт |
|---|---|
| ЗАПЛАНИРОВАНО | CLI [kai](https://github.com/kaizenium/kai): `build`/`run`/`clean`/`add`/`remove`/`update` |
| ЗАПЛАНИРОВАНО | [kai-syntax](https://github.com/kaizenium/kai-syntax): подсветка синтаксиса для редакторов (VSCode, Vim) |
| ЗАПЛАНИРОВАНО | [kaifmt](https://github.com/kaizenium/kaifmt): форматтер кода |
| ЗАПЛАНИРОВАНО | [kaistd](https://github.com/kaizenium/kaistd): минимальная стандартная библиотека (I/O, строки, коллекции) |
| ИДЕЯ | [kaitest](https://github.com/kaizenium/kaitest): инструмент тестирования |
| ИДЕЯ | [kaibench](https://github.com/kaizenium/kaibench): инструмент бенчмаркинга |

## Где Мы Сейчас?
 
Проект находится на **Фазе 0** - спецификация языка находится в активной разработке. Переход к Фазе 1 (Лексер и Парсер) начнётся, как только спецификация станет достаточно стабильной для дальнейшей работы.
 
## Хотите Внести Вклад?
 
На данном этапе наиболее ценным вкладом являются обсуждение и отзывы по спецификации [about-kai](https://github.com/kaizenium/about-kai). Отдельный призыв к вкладу в код будет объявлен, когда начнётся Фаза 1.
