# Kai ロードマップ

このドキュメントは、Kai言語とそのエコシステムの開発順序を記録しています。フェーズは日付順ではなく依存関係順に並んでいます - 各フェーズは前のフェーズの中核的な成果物を必要とします。これは、現在仕様策定段階にあるプロジェクトにとって現実的なコミットメントのレベルです。
 
## ステータス凡例
 
| ラベル | 意味 |
|---|---|
| 完了 | 完了済み |
| 進行中 | 現在作業中 |
| 予定 | 計画済み、未着手 |
| 検討中 | 検討中、未確定 |
 
---
 
## フェーズ0 — 言語設計
 
**目標:** 構文とセマンティクスを紙の上で確定させる。
 
| ステータス | 項目 |
|---|---|
| 完了 | 設計思想と対象領域の定義 |
| 進行中 | v0.1言語仕様 ([about-kai](https://github.com/kaizenium/about-kai)) |
| 予定 | 構文例の拡充（エッジケース: ジェネリック制約、演算子オーバーロード規則、マクロシステムの詳細） |
| 予定 | 仕様に対するコミュニティフィードバックの収集 |
 
## フェーズ1 — 字句解析器とパーサー
 
**目標:** Kaiのソースコードを AST に変換できる最小限のフロントエンド。
 
| ステータス | 項目 |
|---|---|
| 予定 | 字句解析器: トークン定義、文字列/文字/数値リテラルの処理 |
| 予定 | パーサー: 式・文の文法、優先順位規則 |
| 予定 | AST定義 |
| 予定 | パーサーのエラーメッセージ（行/列情報付き） |
 
## フェーズ2 — 意味解析
 
**目標:** 動作する型チェックと基本的な検証。
 
| ステータス | 項目 |
|---|---|
| 予定 | シンボルテーブルとスコープ解決 |
| 予定 | 型チェック (`i8`-`i64`、`u8`-`u64`、`f32`/`f64`、`bool`、`char`、`str`) |
| 予定 | struct/classのフィールドおよびメソッド解決 |
| 予定 | 可視性ルールの適用 (`public`/`private`/`protected`) |
| 予定 | ジェネリック型の解決 (`Vector<T>`) |
 
## フェーズ3 — コード生成
 
**目標:** 検証済みASTを実際に動作するx86-64アセンブリに変換する。
 
| ステータス | 項目 |
|---|---|
| 予定 | 基本式と制御フローのコード生成 (`if`/`for`/`while`/`switch`) |
| 予定 | 関数呼び出し規約、スタックフレーム管理 |
| 予定 | struct/classのメモリレイアウト |
| 予定 | インラインアセンブリ (`asm {}`) ブロックの統合 |
| 予定 | リンカーによるNASM/GAS出力の結合 |
| 予定 | マイルストーン: "Hello World" の実行 (Linux x86-64) |
 
## フェーズ4 — コンパイラの成熟
 
**目標:** 実用的なプログラムが書けるようにする。
 
| ステータス | 項目 |
|---|---|
| 予定 | 手動メモリ管理下でのポインタ/参照のコード生成 |
| 予定 | コンストラクタ/デストラクタの呼び出し順序、継承と仮想ディスパッチ |
| 予定 | constexpr評価 |
| 予定 | マクロシステムの実装 |
| 予定 | コンパイラのエラー・警告メッセージの改善 |
| 検討中 | 基本的な最適化パス（デッドコード削除、定数畳み込み） |
 
## フェーズ5 — ツールエコシステム
 
**目標:** 言語を日常的に使えるものにする。
 
| ステータス | 項目 |
|---|---|
| 予定 | [kai](https://github.com/kaizenium/kai) CLI: `build`/`run`/`clean`/`add`/`remove`/`update` |
| 予定 | [kai-syntax](https://github.com/kaizenium/kai-syntax): エディタ向けシンタックスハイライト (VSCode, Vim) |
| 予定 | [kaifmt](https://github.com/kaizenium/kaifmt): コードフォーマッター |
| 予定 | [kaistd](https://github.com/kaizenium/kaistd): 最小限の標準ライブラリ (I/O、文字列、コレクション) |
| 検討中 | [kaitest](https://github.com/kaizenium/kaitest): テストツール |
| 検討中 | [kaibench](https://github.com/kaizenium/kaibench): ベンチマークツール |

## 現在の状況は？
 
プロジェクトは現在**フェーズ0**にあり、言語仕様が活発に策定されています。フェーズ1（字句解析器とパーサー）への移行は、仕様がそれを基に構築できるほど安定した時点で開始されます。
 
## 貢献したいですか？
 
現段階で最も価値のある貢献は、[about-kai](https://github.com/kaizenium/about-kai) 仕様についての議論とフィードバックです。フェーズ1が始まり次第、コード貢献のための別途の呼びかけが行われます。
